Build it once, then upload and approve one catalog release for reuse across all compatible devices. It must be started with the firmware-build Compose profile; the builder is not needed for normal Hub operation.

Browser flashing (administrator)

            
Flash compatible registered firmware or test a candidate using a supported Chromium-based browser over HTTPS. Choose an active device and compatible firmware. Registered releases are ready for deployment; unregistered candidates are marked and can be flashed by an administrator for hardware verification before promotion. The safer option reads the dBmap device ID first. If that does not work, an administrator can explicitly confirm the physical device selection and continue; ESP Web Tools detects the chip family, not the dBmap node ID.

            

              
              
            

            
Compatibility checks use the registered device type and either a generic hardware profile or an exact recorded board revision. The Hub cannot verify the chip platform from the device record, so confirm the selected firmware chip family matches the physical board.

            
When ESP Web Tools asks “Erase device?”, leave the “Erase device” checkbox unchecked and choose “Next”. Erasing clears NVS, including the Hub device identity and configuration. Flashing does not inject Wi-Fi credentials. Candidate flashes are listed in install history for admins but do not promote the release.

Configure device over USB

              
Admin-only. Writes Wi-Fi and call-home settings into device NVS over USB. Bootstrap token is optional: omit it to keep the device's existing NVS token. Provisioned boards open a 10-second USB window after reset. Secrets are sent only to the board and are not stored by the Hub. A confirmed NVS write does not prove Hub connectivity.

    ESPConnect
    
            
    ESPConnect v1.1.23 is hosted as static files on this Hub. It can inspect supported ESP32 and ESP8266 boards over USB, including device and chip information, without loading the app from the internet.
    
            
    ESPConnect accesses the USB serial device directly from your browser. Use a Chromium-based browser, connect the board to this computer with a data-capable USB cable, then grant access when prompted. Close other serial tools first.
    
            
    
              Open ESPConnect v1.1.23 in a new window
              ESPConnect v1.1.23 release notes
            
    
            
    The board inspection runs locally in your browser. dBmap does not send ESPConnect your Hub access token or automatically register the detected board; linking device inspection to the registration form is a later step. Release notes and help links still require internet.
